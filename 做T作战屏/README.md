# 做T作战屏 · 永鼎股份 (600105)

单文件 HTML 盘中做T盯盘页（手机/桌面浏览器直接打开即用）。

## 功能
- **三个页签**：周一盘前计划 · 周五回放(10-30 复盘, +546.51) · 实盘盯盘
- **实盘引擎**：tdt2 口径移植（5分K走盘 · 反弹线=卖点起算动态下移+0.15 · IV缺口区五级实时重扫:日/30/15/5/1分）
- **数据源**：东财+腾讯（与金粼持仓页生产同链：分时含竞价段/1分K=东财优先，5/15/30分K+日K=腾讯优先，互为兜底，零新浪）
- **盘中提醒**：9:25 开盘判定(低开→开盘卖) · 反弹线到价(蜂鸣+弹窗, 8秒级) · 到卖目标 · 14:55 兜底 · 当日必平
- **分时图**：分钟级分时线 + 竞价段(9:15-9:25撮合指导价) + IV缺口区/磁铁价位线

## 用法
交易日 9:00-15:10 打开页面自动进实盘页；蜂鸣需先点一下页面激活。页面须保持打开才盯盘；提醒≠下单，人眼关卡。
- `tdt2.js`：引擎原版（Node 复盘工具，页面引擎=其口径移植）
